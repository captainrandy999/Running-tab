# Running Tab — Simple

Running Tab tracks who owes you money, whom you owe money to, reasons, and a running total per person.

## Use on your Samsung

After enabling GitHub Pages at **Settings → Pages → Deploy from a branch → main → /(root)**, open:

https://captainrandy999.github.io/Running-tab/

Tap **🎤 Dictate**, allow Chrome microphone access, speak your entry, then tap **Review → Confirm & save**. You can always type or use the Samsung keyboard microphone as an alternative. Voice transcription may need internet.

## Test data

For now this is a test version. Transaction data is stored in your phone's browser localStorage, not GitHub. Clearing the site's storage deletes it. The GitHub code is public.

For real records, add backup/export before relying on the app for bookkeeping.
